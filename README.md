# hydra_vision_reborn
A continuation of the senior year capstone project of Benjamin Adams, Shem De Leon, James Headrick, Emma Jepson,
Christopher McCarthy, James Miles, Aria Varwig, and Jayshon Vernor. 

* Documentation and files from original semester project can be found [here](/hydravision_semester_files).
  
### Description

This project aimed to create a robot using ROS 2 intended for search and rescue. The robot would be used to look for a dedicated object (with the final intended object to be people) with a stereo camera running a machine learning algorithm trained to detect that object. The robot would use a LIDAR and positional data to navigate and map it's environment while it searched.
